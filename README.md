### 📖 개요  

이 프로젝트는 **Unity 3D**로 개발된 

**SNG**(Social Network Game) + **RPG**(Auto Battle) + **SLG**(전략 시뮬레이션) 복합 장르의 **모바일 게임**입니다.



### 🧠 **핵심 루프 (Core Loop)**

1. 생활 경영 (Idle Production / SNG)

   - AI 고양이, 곰들이 **자동으로 음식(자원)를 생산**
   - 시설 업그레이드 → 더 많은 생산량 → 더 많은 수익

2. 캐릭터 육성

   - 캐릭터가 일을 하거나 전투에 참여시 경험치 획득
   - 각 캐릭터마다  스킬과 **랜덤한 스탯**이 존재
   - **가챠 시스템**을 통한 캐릭터 뽑기 와 캐릭터 꾸미기 시스템

3. 전투 (RPG 요소)

   - 육성된 캐릭터들이 팀을 이루어 몬스터와 전투
   - **자동 전투 + 수동 스킬 사용** 조합 (Semi-Auto Battle)

4. 맵 확장

   - 특정 전투 승리 시 새로운 지역 해금
   - 새로운 자원 생산지, 고양이 종류, 몬스터 등장

5. 순환 구조

   - 맵 해금 → 더 많은 자원 → 더 좋은 고양이 → 더 강한 전투 → 더 넓은 맵

### 🚀 주요 기능  

1. **AI**: FSM(Finite State Machine)을 이용하여 캐릭터들의 상태를 자동으로 변경하고 관리하는 시스템
2. **건설 시스템**:  건축물을 설치하고 파괴할 수 있어 자유로운 맵 구성이 가능
3. **음식 생산 시스템**: 다양한 **음식과 재료**를 생산할 수 있는 시스템, **요리 건물에 들어간 채소**에 따라 다른 음식을 만들 수 있으며, **업그레이드 기능** 제공
4. **전투 시스템**: 실실시간 자동 전투와 **유저 스킬** 사용을 통한 전투 시스템
5. **퀘스트/업적 시스템**: 퀘스트와 업적을 통해 **재화**를 수급하는 시스템
6. **챕터 시스템** : **챕터**를 통해 콘텐츠를 해금하고 새로운 기능을 경험할 수 있는 시스템
7. **장비 착용 시스템**:  **곰냥 수납장**을 통해 장비를 장착하고, **장착된 장비 미리보기** 기능 제공
